# 🏋️ Журнал клиентов тренера

Лёгкое приложение для персонального тренера: клиенты, абонементы и оплата, замеры тела, фото «до/после» и история тренировок. Один файл `index.html`, без сборки и без сервера.

## Возможности

- **Клиенты** — список, поиск по имени, цель, рост, телефон, заметки.
- **Абонементы и оплата**
  - пакеты занятий (4, 8, 12, 16 и т. д.), дата оплаты, срок действия (по умолчанию 35 дней);
  - отметка занятия или пропуска в один тап, остаток считается автоматически;
  - статусы: активен / скоро истекает / срок истёк / завершён;
  - расчёт за период: выручка, аренда зала (выручка минус вычет), отметка «оплачено»;
  - редактируемый прайс и поле для заметок и задач.
- **Замеры** — вес, грудь, талия, бёдра, бицепс, бедро; график динамики и изменение с первого замера.
- **Фото** — «до», «прогресс», «после», автоматическое сравнение первого и последнего фото.
- **Тренировки** — дата, название, список упражнений.
- Светлая и тёмная темы, адаптивная вёрстка для телефона.

## Запуск

Откройте `index.html` в браузере двойным щелчком. Больше ничего не нужно.

### Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы этого проекта.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту приложение откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

> Если в приложении будут реальные клиенты, пользуйтесь им с одного устройства или делайте резервные копии (см. ниже). Сами данные в репозиторий не попадают.

## Где хранятся данные

Все данные хранятся **только в вашем браузере**: тексты и цифры в `localStorage`, фото в `IndexedDB`. На GitHub и на любой сервер ничего не отправляется.

Это значит:

- на другом устройстве или в другом браузере данные не появятся автоматически;
- очистка данных сайта в браузере удалит журнал.

**Резервная копия.** Кнопка **⬇ Экспорт** сохраняет всё (включая фото) в файл `trainer-journal-ГГГГ-ММ-ДД.json`. Кнопка **⬆ Импорт** восстанавливает данные из такого файла и переносит их на другое устройство. Делайте экспорт регулярно, например раз в неделю.

⚠️ **Не публикуйте файлы экспорта в репозитории**: в них персональные данные клиентов. Они уже добавлены в `.gitignore`.

## Демо-данные

В `docs/demo-data.json` лежит вымышленный пример. Чтобы попробовать приложение, нажмите **⬆ Импорт** и выберите этот файл.

## Как настроить под себя

- **Срок действия абонемента** и **прайс** хранятся в настройках приложения (`days`, `pl` в функции `DEF()` внутри `index.html`). Цены можно менять прямо во вкладке «Абонементы».
- **Цвета** задаются переменными в начале `<style>` (`--g1`, `--g2`, `--ac` и др.).
